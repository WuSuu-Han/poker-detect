## 二、已实现的功能

### 1. 图像基础与牌面定位

- 保留环境检查、图像基础处理、牌面定位、识别和鲁棒性自测五个原实验脚本。
- 图像基础处理包含尺寸、通道、灰度等操作；通道图使用支持中文路径的保存方式。
- 定位沿用 HSV 白色区域分割、形态学处理、连通域筛选、凸包角点和透视校正的原有流程。
- 透视输出按短边横放处理；诊断输出使用实际选中的阈值组。
- 白度相对阈值增加上限；修正粘连区域分离中的腐蚀次数。

后两项属于实现修正，不代表浅色桌面或重叠遮挡已解决。

### 2. 点数与花色识别

- 对四个方向尝试识别，统一识别坐标中的索引裁剪区域。
- 用字体模板和倒角距离识别点数；“10”同时参考模板和双字符结构。
- 索引块发生粘连时，尝试用行投影谷值拆分。
- 花色结合颜色和形状判断；对适合的牌面，中央重复符号提供投票信息。
- 6／9 在可靠的中央符号计数可用时辅助修正，仍可能出错。
- 支持 Cambria TTC 字体回退；提供模板缓存 `src/cardlib/templates.npz`，减少对队友系统字体的依赖。
- 提供匹配分数、候选差距和 CHECK 提示。分数未经真实验证集校准，不能解释为正确概率；没有 CHECK 也不保证结果一定正确。

### 3. GUI 与批量导出

入口：`src/gui.py`；Windows 推荐双击项目根目录的 `run_gui.cmd`。

- 选择一张／多张图片，或批量处理文件夹中的图片。
- 显示带检测框的原图，以及摆正后的单牌图、点数、花色和匹配分数。
- 识别在后台线程进行，界面通过队列接收结果。
- 对需要核对的结果显示 CHECK。
- 导出 CSV、JSON、标注图片和单张牌图。
- 提供 `src/batch_recognize.py`，可通过命令行批量识别并导出。

### 4. 标注与评测工具

| 工具 | 用途 |
| --- | --- |
| `src/robustness_test.py` | 保留原七场景自测入口 |
| `src/benchmark.py` | 生成合成退化与旋转回归的 JSON／Markdown 报告 |
| `src/annotate.py` | 人工点击四角并输入点数、花色，建立独立真值 |
| `src/evaluate.py` | 对人工标注数据进行定位和识别评测 |
| `src/test_tools.py` | 验证匹配、几何、模板缓存、空场景、失败字段、数据泄漏检查 |
| `src/smoke_gui.py` | 验证 GUI 预加载、后台识别、牌面控件和导出流程 |

真实数据评测按 IoU ≥ 0.5 进行一对一匹配，输出定位 precision／recall／F1、点数／花色／整牌准确率、覆盖率、拒识率、已接受结果准确率、逐图匹配 IoU 和混淆计数。无样本或分母为零时返回 N/A。

下表摘自 [已有合成回归报告](docs/benchmark.json)，本次文档编写没有重新测试。

| 原有场景 | 检出数 | 整牌标签多重集合匹配正确数 |
| --- | ---: | ---: |
| 示例原图 | 8 | 8/8 |
| 暗光 45% | 8 | 8/8 |
| 过曝 1.35 | 8 | 8/8 |

修改前原七场景记录为 50/56，修改后为 52/56。新增的不裁切旋转测试中，15°、30°、45°、60°、75°、180°、270°为 8/8；90°为 6/8。完整结果见 [报告](docs/benchmark.md)。

注意：

- 表中统计是单张示例图的合成变换和标签多重集合匹配，不核对预测牌框位置。
- “检出 8 张”不等于定位精确率 100%；52/56 也不是独立真实照片上的总体准确率。
- 项目此前的 6 项单元测试和 GUI 流程验证已通过；队友更换环境后仍应自行复测。
- `data/real_photos.json` 当前为空，真实拍摄效果没有得到验证。

## 四、接下来需要完成什么

### 优先完成：真实照片验收

1. 采集独立拍摄的多角度照片；建议先准备 20～50 张，覆盖平面旋转、俯拍角度、距离、光照和桌面变化。这是团队采集建议，不是题目规定数量。
2. 保留失败样本，并加入没有牌的负样本。
3. 使用标注工具人工标注四角、点数和花色，不把检测输出直接当作真值。
4. 使用评测工具生成报告，记录成功和失败场景。
5. 根据实际失败原因继续改进识别，再决定是否达到课程验收标准。

同一原始拍摄图片的派生图应使用相同 `photo_id`，不得跨训练／测试集合，避免数据泄漏。

### 已知问题与尚未完成的改进

- 模糊、裁切、部分旋转仍会误识别；黑桃／梅花以及部分点数仍可能混淆。
- 浅色桌面、强反光、不同字体牌面和重叠遮挡尚未完成真实照片验证。
- CHECK 阈值尚未由独立真实验证集校准。
- 局部背景白度比较、多阈值候选融合、边缘分割回退、圆角直线拟合、多字体稳健聚合尚未实现。
- 尚未按独立真实照片统计泛化置信区间。

建议分工：一人负责拍摄与标注，一人负责评测与失败样本整理，算法修改根据评测结果开展。
