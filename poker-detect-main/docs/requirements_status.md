## 本次交付的测试

单元测试覆盖：匹配避免贪心漏配、IoU 与旋转画布、无字体缓存读取、空图识别及导出、失败结果字段、同源照片跨集合泄漏检查。

GUI 集成测试覆盖预加载、队列回传、主线程创建八个牌面控件、CSV/JSON 与八张单牌图导出。没有将 GUI 测试当成识别准确率证明。

旧七场景由 50/56 提升至 52/56，属单示例多重集合计数，不是 52 个独立照片样本，不作为真实场景准确率估计。新增不裁切旋转中 90°仍有误判，详见生成报告。

## 仍存在的算法限制

没有完整解决浅色背景的牌面分割、重叠遮挡、不同牌面字体和强反光。尚未用真实验证集校准 CHECK 阈值。6/9 中央计数只在符号分离可靠时辅助，模糊仍可误识别。

目前保留原来的阈值候选选择和角点算法，没有把所有改进建议都当成已完成：局部背景白度比较、多阈值候选融合、边缘分割回退、圆角直线拟合、多字体稳健聚合和按独立照片 bootstrap 置信区间均未实现。真实数据应先按现有工具评测，再根据具体失败原因决定是否继续改算法。
